Progress backup & recovery

This page manages optional browser-local completion and notes. The interviewing AI produces your revision document; save that Markdown wherever you choose. This site does not receive your AI conversations.

Export progress

Download all current progress and preserved legacy data. Old browser keys are never deleted. Keep a backup before moving to another browser or origin.

Import a backup

Only version 2 progress exports are accepted. Review the preview before applying. Existing values win unless you explicitly allow replacement. Imported recovery data is preserved as an archive; it is not blindly written into live browser keys.

Legacy records needing review

The original DSA page marked early exercises solved automatically. Some LLD numeric IDs referred to different exercises. These records do not count as solved until you confirm the intended target. Leaving them unresolved preserves them in your backup.
